# Support

Signal Engineering Harness is maintained by its project maintainers. Use a
GitHub issue in this repository for reproducible defects, feature requests, and
installation questions. Include the CLI version, operating system, Python
version, redacted command output, and the smallest workspace/profile fixture
that reproduces the problem.

The latest tagged release and the default branch are supported. Older pre-1.0
releases receive fixes only when a maintainer explicitly backports them.

For suspected vulnerabilities, customer-data exposure, leaked credentials, or
other sensitive reports, follow [SECURITY.md](SECURITY.md) instead of opening a
normal issue. Repository access, service ownership, provider credentials, and
domain-contract questions remain the responsibility of each consumer and the
participating repository's owning team.
